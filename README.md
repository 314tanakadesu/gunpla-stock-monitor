# gunpla-stock-monitor

PCのブラウザで在庫状況を確認し、入荷時は設定済みのGitHub Actionsメール通知を利用します。PCを閉じていてもGitHub上で監視します。

## PCで確認する

[在庫チェックの実行一覧](https://github.com/314tanakadesu/gunpla-stock-monitor/actions/workflows/stock-check.yml)をブックマークしてください。最新の実行を開くとSummaryに判定、商品価格、送料、合計、販売元、購入・予約状況、日本時間の確認日時が表示されます。情報を取得できない場合は「判定不能」「確認失敗」と表示します。緑色の実行結果は在庫ありを意味しません。

今すぐ確認する場合は同じページのRun workflowを使います。通常はTest notificationをオフのまま実行します。既にメール受信を確認済みなので、通知設定やテストの繰り返しは不要です。結果はstock-statusアーティファクトからもダウンロードできます。

## 通知条件

- HG 1/144 ガンダムヴァサーゴ（ASIN B0H32PBNFR）の商品タイトルを確認できる。
- 主購入欄に有効な購入または予約ボタンがある（予約も対象）。
- 販売元は制限しない。ただし販売元を読み取れること。
- 商品価格と無条件の送料が確定し、合計が3,190円以下。

商品ページの主購入欄を監視します。「他の出品者」の一覧を全件比較する機能はありません。配送先、ログイン状態、Amazon側のHTML変更によって取得内容が変わります。条件付き送料無料、送料不明、価格が複数あって特定できない場合は通知しません。購入前にAmazonで最終価格・送料・販売元を確認してください。

条件に合う入荷を新たに検出すると「Stock alert - eligible offer detected」のステップを意図的に失敗させ、受信確認済みのActions失敗メールを使います。メールの件名はGitHubの失敗通知です。本文の実行リンクからSummaryを確認してください。実際のプログラム障害も失敗メールになるため、失敗ステップ名で区別します。

同じ入荷が続く間は再通知を抑制し、在庫なし・価格超過を確認した後の再入荷では再通知します。判定不能や接続失敗では通知履歴を維持します。履歴はGitHub Actionsキャッシュに保存するため、キャッシュ消失時は重複通知する場合があります。メール配送成功の確認はできません。

スケジュール指定は5分間隔ですが、実行やメール到着時刻は保証されません。公開リポジトリでは活動が60日ないと定期実行が無効になる場合があります。

## 開発・検証（Python 3.12、追加依存なし）

```text
python -m unittest discover -s tests -v
python monitor.py
python monitor.py --html amazon-sample.html
```

通常実行はstatus.jsonとstatus.md、通知履歴を保存します。HTMLによるオフライン検証は通知履歴を変更せず、通知も発生させません。GitHub上の定期実行はデフォルトブランチのワークフローを使用します。
